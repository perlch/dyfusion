# Markov Chain Neural Text Generator

A minimal neural-inspired text generator built using **Markov Chains** and implemented with pure:

* HTML
* CSS
* Vanilla JavaScript

No frameworks. No libraries. Just raw logic.

---

## About the Project

This project is a simple text generation model based on **Markov chains**.

It analyzes input text (from [Wikipedia](https://www.wikipedia.org/)), builds probabilistic state transitions between words (or characters), and generates new text by traversing those transitions randomly.

The goal of this project was to:

* Understand probabilistic text generation
* Implement a Markov model from scratch
* Build everything using only vanilla web technologies
* Create a minimal and clean UI
